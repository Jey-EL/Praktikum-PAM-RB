## Cara Menjalankan

1. Clone repository ini dari GitHub.
2. Buka project `NewsFeedSimulator` menggunakan Android Studio.
3. Tunggu proses **Gradle Sync** selesai.
4. Hubungkan emulator atau perangkat Android, lalu klik **Run ▶**.
5. Setelah aplikasi terbuka, berita kategori **Technology** akan muncul setiap 2 detik.
6. Tekan **Tandai Sudah Dibaca** untuk menambah jumlah berita yang dibaca.
7. Tekan **Ambil Detail Berita** untuk mengambil detail berita secara asynchronous.
