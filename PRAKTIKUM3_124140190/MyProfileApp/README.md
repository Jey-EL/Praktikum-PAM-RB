## Deskripsi

My Profile App merupakan aplikasi sederhana yang menampilkan informasi profil pengguna.

Aplikasi menampilkan:
- Foto profil
- Nama
- Bio
- Email
- Nomor telepon
- Lokasi

Aplikasi juga memiliki tombol untuk menampilkan dan menyembunyikan informasi kontak.

## Komponen yang Digunakan

Aplikasi menggunakan beberapa komponen dan layout Compose, yaitu:

- Column
- Row
- Box
- Card
- Text
- Button
- Image
- Icon
- AnimatedVisibility

Aplikasi juga menggunakan reusable composable:
- `ProfileHeader`
- `ProfileCard`
- `InfoItem`

## Cara Menjalankan

1. Clone repository ini dari GitHub.
2. Buka project `MyProfileApp` menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Hubungkan emulator atau perangkat Android.
5. Klik **Run ▶**.
6. Aplikasi akan menampilkan halaman profil.
